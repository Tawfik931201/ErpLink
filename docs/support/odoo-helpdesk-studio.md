# ERP Link Helpdesk — standalone Odoo Studio staff workspace

Created **2026-11-24** in the **central ERP Link Odoo** instance.

## Architecture

- **New staff application/menu:** `ERP Link Helpdesk`, `ir.ui.menu` **137**.
- **Original ERP Link storage/data app:** `ir.ui.menu` **130** (unchanged).
- **Single data source:** `x_erplink_support_ticket` / `mail.message` / `ir.attachment`, in central Odoo.
- The new app uses **its own actions and views** on the same ticket model, rather than duplicating tickets or inventing another message store. This preserves the Zid/Odoo integrations and the ERP Link app's original ticket read/write and realtime webhook paths.

## Helpdesk-specific views

- Search: `ir.ui.view` **649**, with subject, customer, email, assignee, status filters and groups.
- List: `ir.ui.view` **650**, with stage, priority, partner, assigned agent, channel and customer-reply dates.
- Kanban: `ir.ui.view` **651**, grouped by stage.
- Form: `ir.ui.view` **652**, with customer info, assignment, stage, priority, request, internal notes, imported history and native Odoo Chatter.

Staff workflow: open a case, assign an agent, set priority/stage and use **Send Message** in Odoo Chatter for a customer-visible reply. Use **Log Note** for private staff-only notes. ERP Link reads only the customer-visible `mail.message` comments of the original ticket. The customer may also send screenshots and files directly from ERP Link.

## Chatter cleanup

The repeated `Subject: [ERP Link] Customer reply on ticket #...` chatter entry was generated by `mail.template` **9** through `base.automation` **2**, on write to the original ticket. Rule **2** was **deactivated**, not deleted; it no longer sends or logs a copy of each customer reply.

The separate **new-ticket notification** (automation **1**) and **realtime message webhook** (automation **3**) remain active. Old outgoing mail messages were preserved for audit purposes.

## Access control: important

Odoo menu/view permissions for the new support app should be configured independently of the original **ERP Link** storage menus. **Do not revoke model-level access to `x_erplink_support_ticket` or `mail.message` from the central integration service account**: the staff UI and the ERP Link application share the same underlying ticket model. Restrict old storage **menus** for staff while allowing staff access to the new Helpdesk app; add appropriate group/model access and record rules if different staff teams need tenant-specific isolation.

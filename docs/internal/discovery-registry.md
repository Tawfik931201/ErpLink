## 3. Discrepancies & Exclusions Resolved

1. **Shopify Returns & Live Stock Sync:**
   - *Finding:* While Zid and Salla have complete bidirectional inventory sync and automated return credit note processing, the Shopify sync engine currently lacks reverse fulfillment/returns (returns webhook resolves to `null` and is skipped) and lacks Odoo-to-Shopify live inventory push.
   - *Resolution:* Documentation accurately reflects current Shopify capabilities (Order sync, Product sync, Customer sync, Initial Transfer) without falsely claiming automated returns or stock push.

2. **Odoo Version Support:**
   - *Finding:* The codebase explicitly tests and handles breaking changes across Odoo 14, 15, 16, 17, 18, 19, and 20 (e.g. `analytic_distribution` in 17+ vs `analytic_account_id` in <=16; `mobile` field removal in 19; `res.partner` child-parent fields in 20; `stock.picking` validation changes).
   - *Resolution:* Documentation clearly explains these version-specific behaviors and compatibility requirements.

3. **Billing System:**
   - *Finding:* As per AGENTS.md, the affiliate system and Stripe payments are permanently removed. Billing is purely manual (bank transfer / manual subscription management by administrator) with an automated 7-day free trial on workspace creation.
   - *Resolution:* Documentation instructs users to contact support/sales for renewals and transparently explains the 7-day trial and countdown.

4. **Security Boundaries:**
   - *Finding:* All sensitive internal secrets (`ENCRYPTION_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, Odoo admin credentials, customer personal data, webhook HMAC salts) are strictly confined to server-side code.
   - *Resolution:* Public documentation and public MCP tools are strictly read-only and contain zero internal credentials.
